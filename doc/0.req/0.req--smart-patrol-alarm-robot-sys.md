# 智能巡逻预警机器人系统需求规格说明书

## 1. 项目概述

### 1.1 背景与目标

本项目面向城市道路场景，研制一套单基站单机器人的智能预警作业系统。系统需实现机器人常态化自动巡逻、定点值守、自主避障、低电量返航，并在匝道等复杂汇入区域支持人工接管安全通过，具备远程调度、实时监控与全流程证据留存能力。

### 1.2 系统组成

系统由机器人端、基站端、云平台/上位机端三部分组成，如下图示意：

<img src="./0.req--smart-patrol-alarm-robot-sys-imgs/media/image1.png" style="width:5.76181in;height:3.77292in" />

**端侧职责定义：**
- **机器人端**：执行路面巡逻、环境感知、障碍避让、视频采集、声光预警、远程语音交互及低电量自动返航。
- **基站端**：机器人收纳存储、自动充电（含机械/视觉引导对接）、本地数据汇聚与缓存、RTK差分基准站。
- **云平台/上位机端**：远程视频监看、任务下发与调度、违法/事件识别（AI辅助）、警情管理、系统运维与日志追溯。

## 3. 智能驾驶（智驾）功能与设计要求

### 3.1 作业模式

| **模式**                 | **描述**                                                                                        |
|--------------------------|-------------------------------------------------------------------------------------------------|
| **自动巡逻**             | 机器人沿应急车道自主巡航，实时回传视频，识别路面异常（抛洒物、坑槽、事故）                      |
| **定点值守**             | 到达指定位置驻停，识别违停、占用应急车道等行为，触发语音劝导并上传证据                          |
| **自主避障**             | 对车辆、行人、遗撒物等进行分类识别，采取“先预警→再减速→后停车”策略，全程不侵入行车道            |
| **低电量返航**           | 电量低于阈值时，自动规划最短路径返回充电舱对接充电                                              |
| **人工接管（匝道模式）** | 行驶至匝道汇入点时，机器人自动停车等待，经人工遥控穿过汇入区后，再继续自动行驶50m，切回自主模式 |

### 3.2 核心算法要求

- **定位与建图**：采用RTK+IMU+轮速+视觉里程计紧耦合融合，动态精度≤10cm；RTK失锁时INS保持≥10s，漂移≤1m，结合高精点云地图匹配保障隧道、树荫等弱信号区定位连续。

- **感知与融合**：激光雷达（100m）+ 毫米波雷达+ 全景相机多源融合，障碍物检测率≥95%，误检率≤5%。
- **避障控制**：感知到执行响应时间≤50ms，避障成功率≥95%，通过性适应≤5cm坑洼、纵坡±6%、横坡±4%的路面。
- **编队与协同**（预留）：支持未来双机或多机协同作业接口，当前版本不强制。
